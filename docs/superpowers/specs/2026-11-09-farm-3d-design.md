# 무야호농장 3D 농장

가로 화면을 기준으로, 로그인하면 농장 장면이 뷰포트를 채운다. Three.js 직교 카메라를 고정 각도로 두고 이동과 확대를 허용한다. 세로 화면에서도 같은 밭을 조작할 수 있다.

장면의 빈 밭에서 씨앗을 고르고, 익은 작물을 눌러 수확한다. 판매대, 확장 표지판, 닭장을 누르면 해당 작업만 열린다. 코인, 가방, 화면 및 계정 설정을 모서리에 놓는다. 이미 저장된 농장의 코인, 작물, 확장 상태는 기존 서버 작업에 연결한다.

건물과 작물, 배경 소품은 원본에서 모델 파일의 MIT 라이선스를 확인하고 가져온다. 모델 출처, 원본 라이선스, 해시를 포함한다. 첫 장면의 배치, 작물 식별, 터치와 확대 조작을 실제 브라우저에서 확인한다.
