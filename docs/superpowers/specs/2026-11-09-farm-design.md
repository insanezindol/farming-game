# 무야호농장

직장인이 잠깐 접속해 직접 작물을 심고 수확하는 모바일 우선 개인 농장이다. 화면에는 비스듬히 내려다보는 2D 농장, 코인, 씨앗과 판매 메뉴를 둔다. 위에서 보는 타일은 조작이 명료하고 메뉴형은 작업이 빠르다. 농장이 커지는 모습을 보여 주기 위해 2D 사선 화면을 선택했다.

밭 6칸에서 밀, 당근, 딸기를 기른다. 밀 45초, 당근 8분, 딸기 2시간으로 시작한다. 로그아웃 중에도 자라고, 다 자란 상태로 기다린다. 수확물을 고정가로 팔고 30코인으로 옆 땅 3칸과 닭장을 연다. 닭은 30분마다 판매할 달걀을 한 개 제공한다.

ID와 비밀번호로 가입하고 다른 기기에서 이어 한다. Supabase Auth는 내부 로그인 식별자를 사용하고 복구 코드는 가입 때 한 번 보여 준다. PostgreSQL은 계정별 농장을 분리하며 수확, 판매, 확장을 한 트랜잭션에서 처리한다. 지인 테스트는 Vercel 접근 보호가 설정된 배포를 사용한다.
