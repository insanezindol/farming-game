# 무야호농장 자유 배치

새 농장은 48×48칸이며 가운데 12×12칸이 열린다. 인접 구역을 코인으로 구매한다. 밭, 축사, 작업장, 장식은 크기, 방향, 고유 ID를 가진다. 편집 모드에서 미리 보고 배치, 이동, 회전, 보관, 일괄 배치와 직전 편집 되돌리기를 한다. 이동과 회전은 생산 시간을 바꾸지 않는다. 집과 판매대도 옮긴다.

작물, 과수, 닭·소·돼지·양·오리·벌의 생산, 낚시, 채집, 작업장 제작 예약, 주문, 판매, 레벨과 수집 도감을 넣는다. 미니맵, 구역 이름, 카메라 저장, 일괄 작업, 작업을 돕는 일꾼을 제공한다. 날씨와 시간대는 연출에 사용한다. 휴식 후에도 완성된 생산물과 주문이 기다린다.

방문 링크는 농장주가 켜고 끌 수 있다. 초대 링크를 가진 방문자는 농장을 구경하고, 로그인 상태에서는 방명록, 선물, 주문 지원을 이용한다. 사진과 공유 화면은 게임 내 편집과 분리한다.

기존 계정으로 새 농장을 시작한다. 서버가 땅 점유, 코인, 시간, 생산 상태를 판정하고 동시에 여러 기기에서 저장할 때 충돌을 검증한다. 농장에 표시하는 3D 모델은 출처의 MIT 고지와 함께 둔다.
