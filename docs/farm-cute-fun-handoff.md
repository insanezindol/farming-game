# 무야호농장 2차 개선 인계서 — 아기자기한 스타일과 다시 하고 싶은 재미

1차 인계서([farm-improvement-handoff.md](farm-improvement-handoff.md))의 **작업 중 유지할 조건**을 그대로 따른다. 특히 아래 원칙은 이번 문서의 "중독성"보다 우선한다.

- 강제 출석, 연속 접속 보상으로 압박하기, 작물 시듦, 놓치면 끝나는 행사는 넣지 않는다.
- 아이템·코인·확률은 서버(`applyFarmCommand`)가 정하고 검증한다. 클라이언트 연출은 결과를 보여주기만 한다.
- 새 3D 모델은 모델 파일 자체에 MIT 라이선스가 적용된 것만 쓴다. 폰트와 음원도 이용 조건을 확인한다. 이번 스타일 작업은 **새 모델 없이 색, 재질, UI, 움직임만으로** 끝낼 수 있게 짰다.

이번에 노리는 재미는 "한 번만 더" 하게 되는 짧은 고리다. 수확할 때의 손맛, 가끔 터지는 깜짝 보상, 다음 해금이 바로 보이는 목표, 모으는 즐거움으로 만든다. 놓칠까 봐 불안하게 만드는 장치는 쓰지 않는다.

## 현재 상태 진단 (2026-11-09, 로컬 미리보기)

- **색감:** 전체 색이 카키와 베이지 쪽으로 가라앉아 있다. 원인은 세 가지다.
  - ACES 톤매핑(`lib/farm-scene.js:129`)이 채도를 눌러 화면이 바랜다.
  - 잔디의 계절 팔레트(`:38-41`)가 탁하다. 가을은 거의 흙색에 가깝다.
  - 안개와 배경(`:135-136`)이 녹갈색이다.
- **UI:** 각진 반경(12px), 딱딱한 `0 3px 0` 그림자, 시스템 기본 글꼴을 쓴다. 정돈돼 있지만 귀여운 느낌은 약하다.
- **반응:** 수확·판매 연출은 있지만, 물체가 놓이거나 수확될 때의 탄력(눌렸다 튀어 오르는 움직임)이 없다.
- **성장:** XP 25마다 레벨이 오르는데, 해금은 Lv.5에서 끝난다. 확장 농장은 Lv.9인데 Lv.6 이후로는 열리는 게 없다.
- **보상:** 수확·낚시·채집 보상이 항상 같다. 낚시는 어종이 순서대로 돌아가고, 쓰다듬기(`pet`)는 효과가 없다.

## 아기자기한 스타일

- [x] **★ 파스텔 팔레트와 톤매핑** — 다음 값을 바꾼다. 같은 위치에서 바꾸기 전후 스크린샷을 비교한다. 익은 작물과 빈 밭의 대비는 지금보다 약해지면 안 된다.
  - 톤매핑: `ACESFilmicToneMapping`을 `NeutralToneMapping`(또는 `NoToneMapping` + 노출 조정)으로 바꾼다.
  - 계절 잔디:
    - 봄: 연두 `#a8d672`
    - 여름: 맑은 초록 `#8fcf6a`
    - 가을: 살구빛 `#e2c27a`
    - 겨울: 민트빛 흰색 `#e4f0e6`
  - 배경, 안개, 하늘빛: 밝은 하늘색과 크림색 계열.
  - 밤 색(`:784-786`): 회청색 대신 라벤더 `#b9a8e8` 계열.
  - 재질 색표(`:24-35`)와 시설 `color`: 채도를 15~25% 올리고 지붕을 코랄·민트·버터색으로 정리한다.
  - 네 계절을 모두 확인한다.
- [x] **★ 둥글고 말랑한 UI** — `app/farm.css`를 다음처럼 바꾼다. 휴대폰 가로·세로, 큰 글씨 설정, 키보드 포커스 표시를 확인한다.
  - 패널 반경: 12px에서 18~22px로.
  - 테두리: 2~3px 크림색.
  - 그림자: 딱딱한 그림자 대신 부드럽고 살짝 색이 도는 그림자.
  - 버튼: 누르면 아래로 눌리는 효과(`transform: translateY(2px)`).
  - 글꼴: 둥근 한글 웹폰트(예: Jua 또는 Gowun Dodum, 둘 다 OFL)를 `app/layout.jsx`에서 `next/font`로 불러온다. 라이선스 고지를 남긴다.
  - 글자 대비: WCAG AA 이상을 유지한다.
- [x] **★ 쫀득한 반응(눌렸다 튀어 오르는 움직임)** — 기존 `controller.react()`와 `updateAtmosphere` 흐름에 붙인다. 동작 줄이기 설정에서는 모두 꺼지고, 실패한 명령에는 재생되지 않는다.
  - 시설을 놓을 때: 0.2초 동안 크기 0.6 → 1.12 → 1.
  - 수확할 때: 작물이 위로 납작했다가 튀어 오르며 사라진다.
  - 코인: 숫자가 올라가는 애니메이션과 `+12` 떠오르는 글자.
  - 레벨업: 별가루 파티클.
- [x] **말풍선 이모티콘** — 동물과 시설 위에 작은 감정 말풍선을 띄운다. 쓰다듬으면 ♥, 밤에는 💤, 생산물이 준비되면 해당 아이콘. 기존 라벨 시스템(`data-group`)을 재사용하고, 먼 줌에서는 숨긴다. 색만으로 상태를 구분하지 않는다.
- [x] **둥근 라벨과 꼬리** — 수확·타이머 알약 라벨을 아래 꼬리가 달린 말풍선 모양으로 바꾼다. 익은 작물 라벨은 살짝 통통 튀게 한다(동작 줄이기에서는 멈춤). 겹침 묶음 "×n" 표시는 유지한다.
- [x] **통통한 비율** — 작물과 동물 모델의 표시 크기를 1.1~1.2배로 키워 귀여운 비율을 만든다. 1차 인계서의 "에셋 크기와 재질 통일" 항목과 함께 처리한다. 클릭 판정과 배치 범위는 타일 기준이라 바뀌지 않는지 확인한다.
- [x] **(선택) 툰 셰이딩** — `prepare()`에서 `MeshStandardMaterial`을 `MeshToonMaterial`과 3단 그라디언트 맵으로 바꾸는 옵션. 모든 모델의 인상이 바뀌므로 설정에서 켜고 끌 수 있게 하고, 저사양 품질에서의 프레임을 비교한다.

## 재미와 다시 하고 싶은 이유

각 항목에 연결되는 기존 시스템과 완료 조건을 적었다. ★는 노력에 비해 효과가 큰 항목이다.

- [x] **★ 레벨 사다리 연장** — 지금은 Lv.5 이후 해금이 없다. Lv.6~15 구간에 레벨마다 하나씩 해금을 둔다. 새 장식(기존 모델 색 변형), 작물, 축사 장식, 구역 할인 등이다.
  - 연결: `buildings`·`crops`의 `level`, `Goals`.
  - 완료 조건: 어느 레벨에서든 "다음 레벨에 열려요"가 비지 않는다.
- [x] **★ 쓸어 수확 콤보** — 한 번 쓸어서 수확한 칸 수를 세어 "콤보 ×12"를 띄운다. 10칸 이상이면 XP를 조금 더 준다.
  - 연결: `sweep()`, 수확 명령의 `ids`.
  - 완료 조건: 보너스는 서버가 실제 수확한 칸 수로 계산한다. 같은 밭을 두 번 지나도 한 번만 센다.
- [x] **★ 황금 작물** — 수확할 때 약 3% 확률로 황금 작물이 나온다. 판매가 5배이고 도감에 따로 기록된다.
  - 연결: `harvestCrop`, `discovered`.
  - 완료 조건: 확률은 서버에서 `밭 id + 심은 시각`을 시드로 정한다. 같은 요청을 다시 보내도 결과가 같다. 같은 기능이 테스트로 검증된다.
- [x] **★ 동물 애정도** — 쓰다듬기와 간식으로 하트(1~5)가 쌓인다. 하트가 쌓이면 가끔 두 개 생산(쌍란 등), 이름표 색 꾸미기가 열린다. 하트는 줄어들지 않는다. 하루에 오르는 양에 상한을 둬서 연타가 아니라 꾸준히 돌보는 사람이 얻게 한다.
  - 연결: `pet`/`feed`(`petAt`, `fedAt`), `renameAnimal`.
- [x] **낚시 손맛과 어종 기록** — 찌가 가라앉을 때 누르는 짧은 타이밍 연출을 넣는다. 어종과 크기(cm)는 서버가 시드로 정한다. 연출은 결과를 보여주기만 하며, 놓쳐도 아무것도 잃지 않는다. 어종별 최대 크기를 도감에 기록한다.
  - 연결: `fish` 명령, `stats.fished`.
- [x] **도감 세트 보상** — "밭 작물 세트", "공방 세트", "물고기 세트"를 모두 발견하면 전용 장식을 준다. 발견 도감에 세트별 진행 막대를 붙인다.
  - 연결: `discovered`, 발견 도감 패널.
- [x] **단골 우정 단계** — 이웃 셋(순덕 할머니, 민호 사장, 유나 선생님)에게 납품한 횟수가 쌓이면 우정 단계가 오른다. 단계마다 그 이웃 고유의 선물(장독대, 간판, 꽃 화분 등 기존 모델 변형)과 새 대사가 열린다.
  - 연결: `regulars`, `neighbors`, 주문 대사.
- [x] **떠돌이 상인** — 가끔 입구 길에 상인이 찾아와 희귀 씨앗이나 장식을 물물교환으로 판다. 다음 상인이 올 때까지 머물러서 놓쳐도 손해가 없다.
  - 연결: 주문 슬롯 생성 규칙(`orderSerial` 방식의 결정적 생성).
- [x] **채집과 정리의 깜짝 발견** — 채집하거나 나무·돌을 정리할 때 낮은 확률로 네잎클로버, 도토리, 새 둥지(달걀) 같은 희귀 아이템이 나온다. 도감과 세트 보상에 연결한다.
  - 연결: `forage`, `clear`.
- [x] **제철 작물 보너스** — 계절마다 두 가지 작물의 판매가와 주문 보상을 +20% 한다. 주문 패널과 씨앗 도구에 "제철" 배지를 단다. 심을 작물을 고르는 이유가 생긴다.
  - 연결: `seasonAt`, `seasonEvents`.
- [x] **농장 매력도** — 장식의 종류와 양으로 매력 점수를 계산한다. 점수 구간마다 방문 페이지 배지와 판매대 팁(소액 코인)이 늘어난다. 꾸미는 행동 자체가 성장으로 이어진다.
  - 연결: `publicFarm`, 장식 카테고리.
- [x] **주간 농장 노트** — 매주 가벼운 목표 3개를 낸다(예: 달걀 10개 모으기, 화단 3개 놓기). 달성하면 스티커와 씨앗을 준다. 기한을 놓쳐도 벌칙이 없고 진행도는 다음 노트로 이어진다.
  - 연결: `seasonAt().index`, `Goals`.
- [x] **레벨업 선물 상자** — 레벨이 오르면 상자를 여는 연출과 함께 해금 목록과 작은 선물(씨앗, 장식)을 보여준다. 사진 기능의 마일스톤 촬영 제안과 연결한다.
- [x] **이웃 품앗이 답례** — 방문자가 주문을 도와주면 주인이 우편함에서 답례 선물을 보낼 수 있다. 도와준 이웃 목록을 방명록에 표시한다. 공개 범위는 기존 방문 규칙을 따른다.
  - 연결: `socialCommand`의 `assist`, 방명록.

## 추천 순서

1. **보이는 변화부터:** 파스텔 팔레트 → 둥근 UI → 쫀득한 반응. 이 셋만으로도 첫인상이 크게 바뀐다.
2. **손맛과 보상:** 쓸어 수확 콤보 → 황금 작물 → 레벨 사다리 연장.
3. **애착과 수집:** 동물 애정도 → 도감 세트 → 단골 우정 → 나머지 항목.

## 검수

- 1차 인계서의 **구현 검수** 1~7을 따른다.
- 확률이 들어가는 항목은 같은 요청 id로 다시 보냈을 때 결과가 같은지 테스트한다. 기존 저장본에 새 필드가 없을 때의 기본값도 테스트한다.
- 스타일 항목은 같은 카메라 위치에서 계절 4개와 낮·밤의 전후 스크린샷을 남긴다.

## 검증 결과 (2026-11-09)

- **자동 검증:**
  - `npm test` 30개 통과. 새 규칙 테스트는 `tests/farm-fun.test.mjs`에 있다.
  - `npm run build` 통과.
- **로컬 미리보기에서 확인 (임시 페이지, 로그인 없음):**
  - 봄·여름·가을 팔레트와 툰 셰이딩 화면, 둥근 UI와 Jua 글꼴, 꼬리 달린 라벨.
  - 주간 노트·떠돌이 상인·우정 표시가 있는 주문서, 매력도·우정·도감 세트가 있는 농장 기록.
  - 낚시 타이밍 연출: 놓치면 명령을 보내지 않고, 낚아채면 서버 명령을 보낸다.
  - 휴대폰 가로(844×390) 배치.
- **화면으로 확인하지 못한 것:** 성공 응답이 있어야 보이는 연출이라 서버 테스트로만 검증했다.
  - 연출: 시설 튀어 오르기, 수확 늘었다 사라지기, 코인 숫자·`+N`, 레벨업 선물 상자, 익은 황금 작물 금빛.
  - 기능 흐름: 설정에서 툰 셰이딩을 켜고 끌 때 장면 다시 열기, 답례가 실제 Supabase 방문으로 전달되는 흐름.
  - 화면 조건: 겨울 팔레트, 실제 휴대폰, 큰 글씨·키보드 포커스.
- **남은 한계:** Lv.15 이후에는 새 해금이 없다. 필요하면 같은 방식으로 사다리를 더 늘린다.
