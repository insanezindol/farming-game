# 무야호농장 3차 개선 인계서 — 기다리지 않고 계속 놀 수 있는 농장

1차([farm-improvement-handoff.md](farm-improvement-handoff.md))·2차([farm-cute-fun-handoff.md](farm-cute-fun-handoff.md)) 인계서의 원칙을 그대로 따른다.

- 강제 출석, 연속 접속 압박, 작물 시듦, 놓치면 끝나는 행사는 넣지 않는다.
- 아이템·코인·확률·시간은 서버(`applyFarmCommand`)가 정하고 검증한다. 클라이언트 연출은 결과를 보여주기만 한다.

이번 목표는 **"심어 놓고 나갔다가 다시 들어오는" 행동을 줄이는 것**이다. 한 번 들어오면 10~20분 동안 심기 → 수확 → 가공 → 납품 고리를 여러 번 돌 수 있게 만든다. 나갔다 와도 손해는 없지만, 접속해 있는 동안이 훨씬 재미있게 한다.

## 현재 상태 진단 (2026-11-10)

- **작물 시간이 길다:** 밀(45초)을 빼면 대부분 8분~2시간이다(`lib/farm-catalog.mjs` `crops`). 딸기는 Lv.1 작물인데 2시간이라 첫날부터 "나갔다 오기"를 배운다.
- **동물·과수도 길다:** 30분~1시간(`buildings`의 `seconds`). 한 번 걷으면 다음 생산까지 할 일이 없다.
- **기다리는 동안 할 일이 적다:** 낚시는 3분, 채집은 10분 쿨다운(`lib/farm-game.mjs:647`, `:661`). 시간을 앞당기는 방법은 스프링클러·온실의 0.8배뿐이다(`:388`).
- **레벨 곡선이 직선이다:** XP 25마다 1레벨(`:219`). 시간만 줄이면 XP가 몇 배로 빨리 쌓여 Lv.15 사다리를 하루 만에 다 오른다. **시간 단축과 레벨 곡선 조정은 반드시 함께** 해야 한다.

## 1. ★ 수확 시간 단축표

가장 긴 작물도 15분 안쪽으로 줄인다. 짧은 작물은 "분당 이익"이 높고(손이 많이 감), 긴 작물은 "한 번에 큰 이익"을 준다는 기존 관계는 유지한다.

| 대상 | 지금 | 제안 | 비고 |
|---|---|---|---|
| 밀 | 45초 | 30초 | 쓸어 수확 콤보용 |
| 당근 | 8분 | 2분 | |
| 감자 | 12분 | 3분 | |
| 옥수수 | 20분 | 5분 | |
| 토마토 | 40분 | 7분 | |
| 딸기 | 2시간 | 8분 | Lv.1 작물이라 가장 크게 줄인다 |
| 호박 | 1시간 | 10분 | |
| 포도 | 1.5시간 | 15분 | |
| 닭장 / 오리 연못 | 30분 / 35분 | 5분 / 6분 | |
| 벌통 / 사과나무 / 복숭아나무 | 40분 / 30분 / 40분 | 7분 / 6분 / 8분 | |
| 외양간 / 양 우리 / 돼지우리 | 45분 / 50분 / 1시간 | 8분 / 9분 / 10분 | |
| 공방 레시피 전체 | 1~10분 | 절반 | 밀가루 30초, 케이크 4분 등 |
| 낚시 / 채집 쿨다운 | 3분 / 10분 | 1분 / 5분 | |

- **기존 저장본:** 이미 심어진 작물과 생산 중인 시설의 `readyAt`은 옛 시간 기준이다. 불러올 때 `min(readyAt, plantedAt + 새 시간)`으로 당겨 준다(늦춰지는 경우는 없어야 한다). 동물 시설은 `plantedAt`이 없으므로 `min(readyAt, now + 새 시간)`으로 처리한다.
- **완료 조건:** 위 표 값이 카탈로그에 반영되고, 옛 저장본을 불러오면 남은 시간이 새 시간보다 길지 않다. 테스트로 검증한다.

## 2. ★ 레벨 곡선 조정

- XP 필요량을 레벨이 오를수록 늘린다. 예: 다음 레벨까지 `20 + 10 × 현재 레벨`.
- 목표: 새 농장이 처음 20분에 Lv.4~5, 첫 주 안에 Lv.10 전후, Lv.15는 2~3주.
- **기존 플레이어의 레벨은 절대 내려가지 않는다.** 저장된 `level`과 새 공식의 결과 중 큰 값을 쓴다.
- 완료 조건: 모의 플레이 스크립트(명령을 정해진 순서로 보내는 테스트)로 20분 지점의 레벨을 측정해 문서에 남긴다.

## 3. ★ 물뿌리개 (접속 중 성장 앞당기기)

- 자라는 작물을 누르면 물을 줘서 남은 시간을 30% 줄인다. 한 번 심을 때 한 번만 된다(`crop.watered`).
- 쓸어 수확처럼 드래그로 여러 칸에 물을 줄 수 있다. 물 주는 동안 물방울 연출.
- 비 오는 날(`weather === 'rain'`)에는 심을 때 자동으로 물을 준 상태가 된다. 지금은 화면 효과뿐인 날씨에 의미가 생긴다.
- 완료 조건: 같은 밭에 두 번 줘도 한 번만 반영된다. 감소량은 서버가 계산한다.

## 4. ★ 퇴비 (즉시 수확 아이템)

- 채집에서 나오는 나뭇가지·버섯, 정리에서 나오는 돌 대신 "잡초"를 퇴비통에 넣어 퇴비를 만든다(새 레시피, 새 시설 `compost` Lv.3).
- 퇴비를 작물이나 동물 시설에 쓰면 바로 수확 가능해진다. 주로 15분짜리 포도·돼지우리에 쓰게 된다.
- 채집·낚시 같은 "기다리는 동안 할 일"이 시간 단축으로 돌아오는 고리를 만든다.

## 5. ★ 다음 할 일 알림판

- 화면 한쪽에 "곧 준비되는 것" 3줄을 띄운다. 예: `🥕 당근 6칸 · 0:42`, `🐔 달걀 · 1:15`, `🍞 빵 2개 · 준비됨`.
- 누르면 카메라가 그 위치로 이동한다. 준비된 것이 생기면 살짝 흔들린다(동작 줄이기에서는 멈춤).
- 짧아진 시간이 실제로 "기다릴 만하다"고 느끼게 하는 장치다. 서버 데이터(`readyAt`, `queue`)만 읽으므로 새 규칙이 필요 없다.

## 6. 자동 다시 심기

- 설정에서 켜면, 수확한 밭에 같은 씨앗을 자동으로 다시 심는다(코인이 부족하면 건너뜀).
- 일꾼 오두막(`automateFarm`)의 자동 수확과 같이 쓰면 "들렀다 걷고 다시 심기"가 한 번 쓸기로 끝난다.
- 완료 조건: 씨앗 값은 수확 명령 안에서 서버가 차감한다. 코인 부족 시 그 밭만 빈 채로 둔다.

## 7. 납품 연속 보너스 (한 번 접속하는 동안만)

- 한 접속에서 주문을 연달아 납품하면 "연속 납품 ×3" 보너스가 붙어 보상이 5%씩 늘어난다(최대 +25%).
- 마지막 납품 후 10분이 지나면 조용히 초기화된다. 날짜를 넘겨 이어지는 연속 접속 보상이 아니다.
- 짧아진 생산 시간 덕분에 실제로 연속 납품이 가능해진다.

## 8. 새 레시피 (늘어난 작물을 쓸 곳)

생산량이 몇 배로 늘어나므로 쓸 곳도 늘린다. 기존 공방을 재사용하고 새 모델은 만들지 않는다.

- 빵집: 호박파이(호박 + 밀가루 + 달걀), 옥수수빵(옥수수 2 + 밀가루)
- 잼 공방: 토마토 소스(토마토 3)
- 치즈 공방: 감자 치즈 그라탕(감자 2 + 치즈)
- 도감 "공방 세트"에 자동으로 포함되므로, 기존 세트 완료자에게 보상을 다시 빼앗지 않도록 완료 여부를 저장값 기준으로 유지한다.

## 9. 들판 깜짝 손님 (기다리는 동안의 미니 이벤트)

- 접속 중 1~3분마다 밭이나 길 위에 작은 손님이 잠깐 나타난다: 나비, 고슴도치, 까치. 누르면 소량의 코인·씨앗·도토리를 준다.
- 30초 뒤 조용히 사라지고, 놓쳐도 손해가 없다.
- 등장 위치와 보상은 서버가 `시간 구간 + 농장 id` 시드로 정한다. 같은 손님은 한 번만 받을 수 있다.

## 10. 시설 업그레이드 단계 늘리기

- 지금 `upgrade` 명령이 있으니, 동물 시설과 공방에 3단계까지 업그레이드를 연다.
  - 동물: 단계마다 생산량 +1.
  - 공방: 예약 칸(지금 8개) +2, 제작 시간 -10%.
- 늘어난 코인을 쓸 곳(코인 소모처)이 된다. 업그레이드한 시설은 지붕 색이나 크기가 살짝 달라진다.

## 11. 수집 미니게임: 달걀 받기 / 양털 깎기

- 생산물을 걷을 때 원하면 3초짜리 미니게임을 한다. 성공하면 하나 더(낚시 타이밍 연출과 같은 방식).
- 실패해도 기본 생산량은 그대로다. 설정에서 끌 수 있다.
- 결과는 서버가 시드로 정하고 연출은 보여주기만 한다(2차 낚시와 동일 원칙).

## 12. 업적과 칭호

- "밀 1,000단", "황금 작물 10개", "하루 납품 20번" 같은 업적. 달성하면 방문 페이지에 보이는 칭호를 준다.
- 기존 `stats`와 `records`로 대부분 계산할 수 있다. 장기 목표가 되어 레벨 사다리 이후의 동기가 된다.

## 13. 수확 소리와 진동

- 쓸어 수확할 때 칸마다 음이 하나씩 올라가는 "도레미" 효과음. 콤보가 길수록 화음이 풍성해진다.
- 휴대폰에서는 짧은 진동(`navigator.vibrate`)을 준다. 기존 `audio` 설정과 동작 줄이기 설정을 따른다.
- 짧아진 수확 주기에서 가장 자주 반복되는 행동의 손맛을 높인다.

## 14. 오늘의 농장 한마디 (접속 시작 화면)

- 들어오면 "지난번 이후 달걀 3개, 당근 12칸이 준비됐어요"처럼 쌓인 것을 요약하고 **한 번에 걷기** 버튼을 준다.
- 나갔다 온 사람에게 손해 없이 바로 다음 고리로 들어가게 한다. 출석 보상은 아니다.

## 추천 순서

1. **시간 개편 묶음:** 1(시간 단축) + 2(레벨 곡선) + 5(알림판). 반드시 같이 배포한다.
2. **접속 중 손맛:** 3(물뿌리개) → 13(소리·진동) → 6(자동 다시 심기) → 14(한마디).
3. **늘어난 생산의 소모처:** 8(새 레시피) → 10(업그레이드) → 7(연속 납품).
4. **보너스 재미:** 4(퇴비) → 9(깜짝 손님) → 11(미니게임) → 12(업적).

## 검수

- 1차 인계서의 **구현 검수** 1~7을 따른다.
- 시간이 바뀌는 항목은 옛 저장본(새 필드 없음, 옛 `readyAt`)을 불러오는 테스트를 넣는다. 레벨이 내려가지 않는지 확인한다.
- 확률·시드가 들어가는 항목(9, 11)은 같은 요청 id로 다시 보냈을 때 결과가 같은지 테스트한다.
- 경제 확인: 모의 플레이로 "처음 20분 동안 번 코인"과 "레벨"을 시간 단축 전후로 비교해 표로 남긴다. 코인이 5배 이상 늘면 판매가나 시설 가격을 조정한다.
